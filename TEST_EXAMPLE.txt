HOW TO TEST:
===========================================================================

1. Refresh browser (F5)
2. Click "Load Demo" button OR start a new chat
3. Go to "Data Collection" phase (first phase)
4. Copy ONE of the examples above
5. Paste it in the text box
6. Click "Analyze with AI" button
7. Wait 2-5 seconds
8. See the complete results with:
   - Total rooms detected
   - Load calculations for each room
   - Regional standards applied (Middle East for Iran)
   - Temperature range groupings
   - Equipment selection recommendations

===========================================================================
WHAT HAPPENS:
===========================================================================

✅ Parser automatically detects:
   - Project name (first line)
   - Location (extracts country/city)
   - Room names
   - Dimensions (length × width × height)
   - Temperatures
   
✅ System automatically:
   - Determines room type (chilling, blast_freezer, storage, cooler)
   - Applies regional standards (ASME, IIAR, ISO based on location)
   - Calculates loads (transmission, product, infiltration, internal)
   - Applies safety factors
   - Selects equipment
   - Generates all 7 phases
